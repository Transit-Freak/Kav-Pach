# שכבות שמועלות לכאן ידנית

שכבות שאין דרך להוריד אותן אוטומטית — או בגלל שאין כתובת קבועה (תלתן),
או בגלל שהשרת חוסם כל בקשה שאינה דפדפן (data.gov.il). מעלים לכאן את
הקובץ כמו-שהוא ותהליך אוטומטי ממיר אותו למה שהאתר קורא.

## איך מעדכנים את גבולות אזורי התעשייה של משרד התחבורה

1. נכנסים בדפדפן לעמוד הדאטהסט "תחום אזורי תעשיה תעסוקה":
   https://data.gov.il/dataset/8db5effd-59ca-44ef-b561-86e0ce2911d1
2. מורידים את הקובץ בפורמט **SHP** (`industrial.zip`).
3. מעלים אותו לתיקייה הזו בשם `industrial.zip` — בלי לפתוח ובלי לשנות.
4. זה הכול. תהליך `fetch-mot-shapes` ממיר אותו לבד, וריצת האתר הבאה
   מציגה את כל 427 האזורים עם הגבול הרשמי של משרד התחבורה.

למה ידנית: שרת ההורדות של data.gov.il מגיש דף JavaScript של הגנת-בוטים
לכל בקשה שאינה דפדפן — כולל דפדפן ללא-מסך. הקובץ עצמו ציבורי לגמרי;
פשוט צריך דפדפן אמיתי כדי לקבל אותו. אם זה ישתנה בצדם, ההורדה
האוטומטית שכבר כתובה תתחיל לעבוד לבד ולא יהיה צורך בשלב הזה.

## תלתן (מערכת המידע התכנוני של משרד התחבורה)

תלתן מאפשרת לייצא שכבות, אבל לא דרך כתובת קבועה שאפשר להוריד ממנה
אוטומטית — ולכן העדכון כאן ידני, וקורה כמה פעמים בשנה.

## איך מעדכנים את מדדי השירות

1. מורידים מתלתן את שכבת **מדדי שירות** בפורמט shapefile (קובץ ZIP).
2. מעלים אותו לתיקייה הזו בשם שמתחיל ב-`madadey` ומכיל את החודש,
   למשל `madadey_shirut_shape_202511.zip`.
3. זה הכול. תהליך `convert-service-indices` ממיר אותו לבד לקובץ
   `parks/checks/service-indices.json`, וריצת האתר הבאה מציגה את
   הציונים המעודכנים. תאריך העדכון נלקח מהמספר בשם הקובץ.

## מה יש בשכבה

לכל אזור סטטיסטי בישראל (3,684) ארבעה מדדים בסולם 0–100 וציון משוקלל:
זמינות (תדירות ופריסת שעות), נגישות (לאן מגיעים בזמן נתון), תחרותיות
(מול רכב פרטי), אמינות (עמידה בלוח הזמנים).
