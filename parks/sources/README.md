# שכבות שמורדות ידנית מתלתן (מערכת המידע התכנוני של משרד התחבורה)

תלתן מאפשרת לייצא שכבות, אבל לא דרך כתובת קבועה שאפשר להוריד ממנה
אוטומטית — ולכן העדכון כאן ידני, וקורה כמה פעמים בשנה.

## איך מעדכנים את מדדי השירות

1. מורידים מתלתן את שכבת **מדדי שירות** בפורמט shapefile (קובץ ZIP).
2. מעלים אותו לתיקייה הזו בשם שמתחיל ב-`madadey` ומכיל את החודש,
   למשל `madadey_shirut_shape_202511.zip`.
3. זה הכול. תהליך `convert-service-indices` ממיר אותו לבד לקובץ
   `parks/checks/service-indices.json`, וריצת האתר הבאה מציגה את
   הציונים המעודכנים. תאריך העדכון נלקח מהמספר בשם הקובץ.

## מה יש בשכבה

לכל אזור סטטיסטי בישראל (3,684) ארבעה מדדים בסולם 0–100 וציון משוקלל:
זמינות (תדירות ופריסת שעות), נגישות (לאן מגיעים בזמן נתון), תחרותיות
(מול רכב פרטי), אמינות (עמידה בלוח הזמנים).
